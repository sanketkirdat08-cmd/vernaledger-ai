Problem Statement

The Burden on Local Merchants

✍️ Manual Data Entry

Writing receipts and ledgers manually is time-consuming and highly prone to human error.

🌍 Language Barriers

Existing software is heavily English-dependent, making it difficult for rural merchants to adopt.

📘 Disorganized Udhari

Tracking who owes money on paper often leads to lost revenue, disputes, and broken trust.

📉 Lack of Analytics

Small businesses struggle to track exact profit, loss, and low stock inventory efficiently.

Project Objectives

Core Pillars of Innovation

📄 Automate Receipt Parsing

Develop a robust OCR engine using Gemini Flash to extract items, prices, and totals instantly.

🎙️ Multi-Lingual Voice Billing

Enable users to speak naturally in Marathi, Hindi, or English to record transactions.

🔒 Secure & Resilient Storage

Implement ACID-compliant SQLite databases with automatic backups and data integrity.

📊 Actionable Intelligence

Provide real-time analytics, AI high-risk credit scoring, and automated WhatsApp reminders.

Proposed System

Use Case & Activity Flow
🧑‍💼
Merchant Actor

Interacts with Streamlit POS UI seamlessly via Voice, Camera, or File Upload.

🧠
AI Parser Module

Gemini LLM converts raw unstructured inputs into a strict, validated structured JSON schema.

💾
Transaction Engine

Commits validated records securely to the local SQLite database ensuring ACID compliance.

🔊
Feedback Loop

Generates Marathi audio voice confirmations and updates UI dashboards in real-time.

Technologies & Tools

The Tech Stack
  • Frontend & Logic Python 3.10+ paired with Streamlit for a highly responsive web interface powered by custom CSS & JS.
  • AI & NLP Engines Google Gemini AI for OCR/JSON parsing, integrated with Edge TTS for ultra-fast Marathi audio synthesis.
  • Database & Analytics SQLite (ACID compliant) for robust local storage, alongside Pandas and Plotly for interactive charts.

⬇

⚙️ OCR & Audio Engine

⬇

🗄️ Database Manager

Manages connection pools, commits receipts, and securely updates khata records.

Working Flow

Sequence Diagram
Step 1

User selects input method (Voice Khata or Live OCR scan).

Step 2

Audio/Image is securely captured and streamed to Gemini LLM.

Step 3

LLM processes data and returns structured JSON containing parsed details.

Step 4

System verifies data integrity and commits transactions to local SQLite.

Step 5

Audio success feedback is played using Edge TTS and UI refreshes.

System Limitations

Known Constraints

🌐 AI Internet Dependency

Core Gemini AI Engine requires a stable internet connection to process complex natural language commands and OCR images.

📸 Image Quality Constraints

Highly distorted, crumpled, or blurry receipts can result in partial extraction failures during the OCR process.
