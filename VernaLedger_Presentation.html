Project Objectives

Core Pillars of Innovation
  • Automate Receipt Parsing Develop a robust OCR engine using Gemini Flash to extract items, prices, and totals instantly.
  • Multi-Lingual Voice Billing Enable users to speak naturally in Marathi, Hindi, or English to record transactions.
  • Secure & Resilient Storage Implement ACID-compliant SQLite databases with automatic backups and strict schema integrity.
  • Actionable Intelligence Provide real-time analytics, AI high-risk credit scoring, and automated WhatsApp reminders.

System Architecture

Component Workflow

UI Layer

Streamlit Interactions

➔

AI Engine

Gemini LLM & Edge TTS

➔

Data Manager

SQLite Commits

Flow: The architecture strictly separates concerns. The UI layer purely handles display and device access (Camera/Mic). The AI engine enforces JSON schemas to prevent hallucination, and the Data manager executes secure SQL transactions.

Working Flow

Execution Pipeline
Step 1

User selects input method (Voice Khata or Live OCR scan).

Step 2

Audio/Image is securely captured and streamed to Gemini LLM.

Step 3

LLM processes data and returns structured JSON containing parsed details.

Step 4

System verifies data integrity and commits transactions to local SQLite.

Step 5

Audio success feedback is played using Edge TTS and UI refreshes.

System Limitations

Known Constraints

🌐 AI Internet Dependency

Core Gemini AI Engine requires a stable internet connection to process complex natural language commands and OCR images.

📸 Image Quality Constraints

Highly distorted, crumpled, or blurry receipts can result in partial extraction failures during the OCR process.
