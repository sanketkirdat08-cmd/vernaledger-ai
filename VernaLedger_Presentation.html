02 • Market Realities

Problem Statement

The Operational Burden on Local & Rural Retail Merchants
✍️

Manual Data Entry

Handwriting bills and physical ledger records consumes 120s+ per transaction, leading to severe calculation errors, lost invoice slips, and peak-hour queue bottlenecks.

Bottleneck: 120s / Bill

Language Barriers

90% of existing accounting software (Tally, Zoho) is English-centric, severely hindering semi-literate rural store owners who communicate exclusively in Marathi or Hindi.

Exclusion: Non-Vernacular UI
📘

Disorganized Udhari (Credit)

Informal customer credit recorded on loose paper notebooks results in uncollected debts, lack of due-date visibility, and over 15% revenue leakage every quarter.

Loss: ~15% Uncollected Debts
📉

Lack of Actionable Analytics

Kirana store owners have zero visibility into real-time profit/loss margins, fast-depleting inventory thresholds, or daily sales patterns to make informed restocking decisions.

Blindspot: Zero Sales Insights

08 • Structural Design

System Architecture

Modular 3-Tier Layered Architecture with Strict Separation of Concerns
1. PRESENTATION LAYER
Streamlit Web Interface • Camera Feed • Speech Mic Input • Interactive DataFrames • Glassmorphic HUD
➔
2. INTELLIGENCE LAYER
Gemini Multimodal OCR • Voice NLP Parser • RAG Query Optimizer • Edge TTS Voice Synthesizer
➔
3. PERSISTENCE LAYER
SQLite Relational Engine • ACID Transactions • WAL Logging • PBKDF2 Hashing • System Audit Log

Architectural Tenet: The UI layer is completely decoupled from processing logic. When user captures a receipt or voice stream, the payload is parsed through isolated LLM validation routines enforcing Pydantic schemas. On successful validation, transactional commits occur atomically in SQLite with rollback protection, guaranteeing data consistency under network dropouts.

09 • Execution Pipeline

Working Flow

Step-by-Step Runtime Lifecycle of an Incoming Transaction
01
Input Trigger

Shopkeeper captures a receipt via live camera, selects an image file, or speaks billing items into the microphone.

02
Streaming

Preprocessed media bytes are transmitted over TLS to Google Gemini Flash API with tailored system prompts.

03
JSON Parsing

AI model performs token extraction, calculates math totals, verifies tax rates, and emits clean structured JSON.

04
ACID Commit

Integrity validator executes atomic SQL statements into ledger.db, updates ledger balances, and creates audit records.

05
Audio & UI

Edge TTS renders Marathi confirmation audio while UI graphs and tables reactively refresh in real-time.
